# Data

The images are not part of this repository. Download Task 1 of the ICPR 2026 competition Beyond Visible Spectrum:
AI for Agriculture from <https://www.kaggle.com/competitions/beyond-visible-spectrum-ai-for-agriculture-2026/data>
(join the competition first) and unpack it here, so that this folder holds `train/{HS,MS,RGB}` with 600 labelled
samples and `val/{HS,MS,RGB}` with the 300 holdout samples. To keep the data elsewhere, set `WHEATRUST_DATA` to
the folder that contains `train/` and `val/`. See the main README for the expected file names and the citation.
